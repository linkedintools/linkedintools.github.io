LinkedIn Koruma & Anlık Web Push Bildirimleri

📱 iOS / Safari Kullanıcıları İçin Önemli:

Apple Web Push politikaları gereği anlık bildirim alabilmek için bu sayfayı Safari'de açıp Ana Ekrana Eklemelisiniz:

  1. Safari alt menüsündeki Paylaş (Share) ikonuna dokunun.
  2. "Ana Ekrana Ekle" (Add to Home Screen) seçeneğini seçin.
  3. Ana ekrandaki LIT Security ikonundan uygulamayı açıp bildirimleri aktif edin.
🔔 Canlı Bildirim Durumu Pasif

Eklenti silinmesi veya şüpheli LinkedIn erişimlerinde bu cihaza anlık Web Push bildirimi gönderilir.

📜 Canlı Adli Olay Günlüğü
Henüz olay günlüğü yüklenmedi. Account ID girip bildirimleri etkinleştirin.
